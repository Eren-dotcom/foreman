Foreman — pre-authorised, refundable pay for AI work

An agent locks a budget on Bitcoin Cash. A provider can only pull whole chunks as it delivers, never more than the window in one transaction. Whatever isn't delivered is refunded by the covenant when the authority expires.

No custodian, no chargeback window, no support ticket. The refund path is the dispute system — and on BCH it costs about a hundredth of a cent to exercise. One 930-byte CashScript contract, three spend paths, every rule enforced by the VM.

    Why BCH: one fee, many payments

    The covenant refuses to merge two pods into one transaction — that would destroy per-pod accounting. So settlement scales the other way: many chunks per input. One signature, one fee, N payments.

    Chunks in one txTx sizeFeeFee per paymentTx

    Pre-execution guard nothing has been sent

    An agent should be able to ask "would this be allowed?" and get an answer that costs nothing. Every intent below is judged against the covenant's own rules on live chain state, and produces a preceipt — a signed-off record of a decision, made before any transaction exists. A refusal is an answer, not an error: it returns 200, with the rule that would have fired.

    guard idle — pick an intent.
    The guard is a courtesy, not the authority. It restates the covenant one step earlier so a bad job never reaches the chain and never costs a fee. The covenant still decides.

    Settlement, rebuilt from the chain books are not evidence

    Foreman keeps a ledger of what it thinks it did. This ignores that ledger completely and rebuilds each pod's finances by walking its real transaction history, then checks one identity: funded = paid + fees + refunded + elsewhere + held. If it does not balance to the satoshi, the reconstruction is wrong and the page says so.

    The gap this fills
    
      
    
        x402 — HTTP 402 for AI agents, now a Linux Foundation project with Visa, Mastercard, Stripe, Google and AWS —
        has three documented holes: no refunds or disputes, no spend ceiling per provider, and
        no BCH settlement. Coinbase's own head of AI product says escrow and refunds are the missing piece.
      
    
      
    
        Foreman is that piece, as a covenant: a budget that cannot be drained, work that cannot go unpaid,
        and money that comes back by itself when the job stops. On BCH a 1-cent refund is economically sane,
        so the refund path can be the dispute mechanism.
